# Personal Portfolio — Michael William Mesina

My personal portfolio website built with vanilla HTML and CSS

## Live Preview

Check out my portfolio: [MWM Portfolio](https://michaelwilliammesina.vercel.app)

## Features

- Sticky navbar with active page highlighting
- Hero section with profile photo and introduction below
- About page with categorized skills badges (Programming and Markup Languages, Frameworks, Backend & Databases, Tools & Environment, Game Development)
- Projects section showcasing featured work with tech stack tags and GitHub/live demo links
- Resume page built directly in HTML with a downloadable PDF option
- Contact page with a working form using Formspree and direct social/contact links

## Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 |
| Form Handling | Formspree |
| Icons | Font Awesome, Devicon |
| Fonts | Google Fonts — Inter |
